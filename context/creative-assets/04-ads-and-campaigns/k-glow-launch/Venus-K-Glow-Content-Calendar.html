Before you start

The design system, in one screen.

Everything below assumes these. If a post does not specify something, it follows these defaults.

Sizes

  • Grid portrait 1080 × 1350
  • Carousel card 1080 × 1350
  • Reel 1080 × 1920
  • Reel cover 1080 × 1920

Safe areas

  • Reels: keep type 250px clear of the bottom, the app UI covers it
  • Reels: 120px clear of the top
  • Reel cover: centre the type inside 1080 × 1440 so the grid crop still reads
  • Carousels: 60px inner margin all round

Type

  • Korean: heavy gothic, always the largest element on the frame
  • English: heavy grotesque, tracking -3%
  • English never bigger than 40% of the Korean size
  • No thin serifs anywhere

Colour

  • Ground #0A0A0B
  • Hot #FF3D77
  • Cyan #5CE1E6
  • Chrome: silver gradient, never flat grey
  • Holo: iridescent, accent only

Fixed elements

  • Chrome K bottom right of every graphic, same size, same position
  • Korean heading top left, English directly beneath
  • Never centre the type unless the post says so

Photography

  • Direct on-camera flash, hard shadows
  • Never soft spa lighting
  • Every face comes from the 23 August shoot
  • No AI faces, no AI skin, ever
  • Before and after: identical light, no smoothing
Where a post says ref D6 or similar, that is a prompt ID in the Creative Kit document. Generate it and use the output as a visual reference only, then set the real Korean type over the top. Never ship AI-generated Korean. It comes out wrong every time.
