# How to Use This Skill

Hey Claude—I just added the "google-ads-weekly-brief" skill. Can you create a weekly report for my client?

## Example Invocations

**Example 1: Client Report**
Hey Claude—I just added the "google-ads-weekly-brief" skill. Here's my performance data for this week vs last week. Can you write a client-friendly weekly brief? Target CPA is $45.

**Example 2: Executive Summary**
Hey Claude—I just added the "google-ads-weekly-brief" skill. I need a quick executive summary for my CMO. Just the highlights—she has 30 seconds to read it.

**Example 3: Slack Update**
Hey Claude—I just added the "google-ads-weekly-brief" skill. Can you format this week's performance as a Slack message I can post to our #marketing channel?

**Example 4: Internal Team Brief**
Hey Claude—I just added the "google-ads-weekly-brief" skill. Create an internal weekly brief with full tactical details. My team knows Google Ads well.

**Example 5: Bad Week Report**
Hey Claude—I just added the "google-ads-weekly-brief" skill. Performance was rough this week—help me write an honest but professional update that shows we have a plan.

## What to Provide

**Required:**
- This week's metrics: spend, conversions, CPA or ROAS
- Last week's metrics for comparison
- Week dates

**Recommended:**
- Target CPA/ROAS
- Monthly budget and goals
- Audience type (executive, client, internal)
- Top/bottom campaign performers

**Optional:**
- Actions taken this week
- External context (promos, seasonality)
- Specific concerns to address

## What You'll Get

1. **Headline** - One-sentence performance summary
2. **Scorecard** - Visual metrics snapshot with traffic lights
3. **Story** - Wins, concerns, and context explained
4. **Campaign Highlights** - Top and bottom performers
5. **Actions** - What was done + what's planned
6. **Pacing** - Month-to-date progress vs goals

## Output Format Options

- **Email** (default) - Subject line + formatted body
- **Slack** - Condensed with emoji, code blocks
- **Slides** - Bullet points per slide
- **Executive** - 3 sentences max

Just specify which format you need!

## Pro Tips

- Send the same data every week for consistent formatting
- Mention your audience so I can adjust the tone
- Include "why" context for unusual performance
- Share last week's recommendations so I can reference what was done
