# How to Use This Skill

Hey Claude—I just added the "facebook-ads-monthly-report" skill. Can you help me create a monthly performance report for my Facebook Ads?

## Example Invocations

**Example 1: Full Monthly Report**
Hey Claude—I just added the "facebook-ads-monthly-report" skill. Here's my January data, can you create a comprehensive monthly report?

**Example 2: Client Report**
Hey Claude—I just added the "facebook-ads-monthly-report" skill. I need to send a monthly report to my client. They care most about ROAS and conversions. Here's the data.

**Example 3: Internal Review**
Hey Claude—I just added the "facebook-ads-monthly-report" skill. We had a tough month and I need to present to my team. Can you help me structure the narrative?

**Example 4: Quick Summary**
Hey Claude—I just added the "facebook-ads-monthly-report" skill. I need an executive summary for this month's performance. What were the key wins and challenges?

## What to Provide

**Required:**
- This month's metrics (spend, conversions, CPA/ROAS, CTR, CPM)
- Last month's metrics (for comparison)
- Your goals/targets

**Recommended:**
- Campaign-level breakdown
- Key changes made this month
- Top performing ads
- Any external factors (holidays, sales, etc.)

**Optional:**
- Creative test results
- Year-over-year comparison
- Audience performance breakdown

## What You'll Get

1. **Executive Summary** - Quick overview answering "how did we do?"
2. **Goal Tracking** - Clear status on each target
3. **Performance Analysis** - Month-over-month with context
4. **Campaign Breakdown** - What worked, what didn't
5. **What Worked / What Didn't** - Honest assessment
6. **Next Month Plan** - Specific priorities and actions

## Pro Tips

- Export data from Ads Manager for accuracy
- Include context about changes you made (budget, creative, audiences)
- Note any external factors that affected performance
- Be honest about misses—the report helps you address them
