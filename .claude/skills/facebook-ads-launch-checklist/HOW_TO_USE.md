# How to Use This Skill

Hey Claude—I just added the "facebook-ads-launch-checklist" skill. Can you help me verify my campaign is ready to launch?

## Example Invocations

**Example 1: New Campaign Launch**
Hey Claude—I just added the "facebook-ads-launch-checklist" skill. I'm about to launch my first Facebook Ads campaign. What should I verify before going live?

**Example 2: New Account Setup**
Hey Claude—I just added the "facebook-ads-launch-checklist" skill. I just set up a new ad account for a client. Walk me through the pre-launch checklist.

**Example 3: Troubleshooting Launch**
Hey Claude—I just added the "facebook-ads-launch-checklist" skill. I launched campaigns yesterday but I'm not seeing any conversions. Can you help me diagnose what might be wrong?

**Example 4: Quick Verification**
Hey Claude—I just added the "facebook-ads-launch-checklist" skill. I need a quick checklist for the most critical things to verify before launch.

## What to Provide

**Required:**
- What you're launching (new campaign, new account, new client)
- Campaign objective (conversions, leads, traffic)
- Whether you've tested your pixel/tracking

**Recommended:**
- Landing page URL
- Conversion event you're optimizing for
- Audience type and size
- Creative types (video, static, carousel)

**Optional:**
- Screenshots from Events Manager
- Campaign structure details
- Any specific concerns

## What You'll Get

1. **Complete Checklist** - Tiered by priority (Critical, Important, Optimization)
2. **Verification Steps** - How to check each item
3. **Issue Documentation** - Any problems found and how to fix
4. **Launch Decision** - Clear yes/no/conditional recommendation
5. **Post-Launch Plan** - What to monitor after going live

## Pro Tips

- Install the Facebook Pixel Helper Chrome extension before starting
- Complete at least one test conversion before checking the boxes
- Test your landing page on an actual mobile device, not just desktop
- Have Events Manager open during verification
