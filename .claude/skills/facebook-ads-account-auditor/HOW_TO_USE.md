# How to Use This Skill

Hey Claude—I just added the "facebook-ads-account-auditor" skill. Can you audit my Meta Ads account and tell me what's broken?

## Example Invocations

**Example 1: Full Account Audit**
Hey Claude—I just added the "facebook-ads-account-auditor" skill. Here's my account data, can you do a full health check?

**Example 2: Specific Problem Investigation**
Hey Claude—I just added the "facebook-ads-account-auditor" skill. My CPA has increased 40% over the last month. Can you help me figure out why?

**Example 3: New Account Setup Check**
Hey Claude—I just added the "facebook-ads-account-auditor" skill. I just set up my first campaigns. Can you check if everything is configured correctly?

**Example 4: Pre-Scale Audit**
Hey Claude—I just added the "facebook-ads-account-auditor" skill. I want to increase my budget from $5k to $20k/month. Is my account ready to scale?

## What to Provide

**Required:**
- Number of active campaigns and their objectives
- Last 30 days performance (spend, conversions, CPA/ROAS)
- Basic tracking info (pixel installed? which events?)

**Recommended:**
- Campaign and ad set structure details
- Audience types and sizes being used
- Number of ads and creative types
- How long campaigns have been running

**Optional:**
- Screenshots from Ads Manager
- Historical performance trends
- Specific concerns or questions

## What You'll Get

1. **Executive Summary** - Overall health score across 5 key areas
2. **Estimated Impact** - How much the issues might be costing you
3. **Detailed Findings** - Deep analysis of each area with specific issues
4. **Prioritized Action Plan** - What to fix first, second, and ongoing
5. **Expected Outcomes** - Realistic projections if fixes are implemented

## Pro Tips

- Export campaign data from Ads Manager for more accurate analysis
- Check your Pixel Helper browser extension before the audit
- Have your Events Manager open to answer tracking questions
- Note any recent changes (budget, audience, creative) in the last 30 days
