# Ad Copy A/B Variant Writer (Meta Ads)

Most Meta advertisers test 2 to 3 copy variants. Top performers test 8 to 12. The discipline that makes testing readable is changing one variable at a time.

## Required data

The current best-performing ad copy: primary text, headline, description, CTA. Performance context helps but is not required.

## Analysis instructions

Act as a Meta Ads copywriter specializing in direct response. Generate 8 variants using this testing framework:

1. **HOOK VARIANT** (2 versions). Change only the first line or hook. Test question vs. statement vs. statistic.
2. **SOCIAL PROOF VARIANT** (2 versions). Add or change the social proof element: reviews, user count, results.
3. **BENEFIT FRAMING VARIANT** (2 versions). Same offer, reframed. Pain-point focus vs. aspiration focus.
4. **CTA VARIANT** (1 version). Change CTA text and urgency level.
5. **LENGTH VARIANT** (1 version). If the original is long, write a short version, or the reverse.

For each variant:

- Label which variable changed
- Explain what is being tested and why
- Keep everything else identical to the original
- Follow Meta's ad copy conventions: roughly 125 characters of primary text are visible before "See More"

Format: `Variant # | Variable Tested | Primary Text | Headline | Description | CTA`

## Operating notes

- Only one variable per variant. If the hook and the CTA both change, the result is uninterpretable.
- Run each variant for at least 2,000 impressions before judging.
- Any social proof used must be real. Never invent review counts, user numbers or results.
